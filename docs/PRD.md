# MarkdownIsAllYouNeed — 产品需求文档 (PRD)

> 使用 Markdown 作为自己的工作语言，随时随地工作

## 1. 产品概述

一款 iOS Markdown 编辑器，核心卖点是 **所见即所得的编辑体验** + **GitHub 仓库直连** + **AI 辅助写作**。用户可以在手机上直接浏览、编辑 GitHub 仓库中的 Markdown 文件，通过 AI Chat 辅助写作，并以标准 Git 工作流提交和推送。

### 1.1 目标用户

- 第一阶段：开发者自用
- 第二阶段：面向有 GitHub + Markdown 写作需求的技术用户发布到 App Store

### 1.2 平台规划

| 阶段 | 平台 |
|------|------|
| MVP | iPhone (iOS 17+) |
| V2 | + iPad（利用大屏分屏） |
| V3 | + Android（编辑器可复用） |

## 2. MVP 功能范围

### 2.1 GitHub 集成

| 功能 | 说明 |
|------|------|
| OAuth 登录 | 通过浏览器授权登录 GitHub |
| 仓库列表 | 展示用户所有可访问的仓库（个人、Fork、组织），优先展示自己的仓库 |
| Clone / Pull | 将仓库克隆到本地，支持拉取最新内容 |
| 文件浏览 | 树形结构浏览仓库内所有文件 |
| Commit | 手动填写 commit message，选择要提交的文件 |
| Push | 推送本地 commit 到远端 |
| 冲突检测 | 检测远端是否有新变更，提示用户选择如何处理 |

**不包含**：创建新仓库、分支管理、PR/Issue 管理（留给后续版本）

### 2.2 Markdown 编辑器

**编辑模式**：所见即所得（WYSIWYG），类似 Typora 的体验。在同一个视图中编辑并实时渲染。

**支持的元素**：

| 类别 | 元素 |
|------|------|
| 文本 | 标题 H1-H6、段落、粗体、斜体、删除线 |
| 列表 | 有序列表、无序列表、任务列表 (checkbox) |
| 代码 | 代码块（语法高亮）、行内代码 |
| 结构 | 引用块、分割线、表格 |
| 媒体 | 图片（存入 GitHub 仓库）、链接 |
| 高级 | 数学公式 (LaTeX)、Mermaid 图表、脚注 |

**图片处理**：
- 插入图片时，图片文件直接存入当前 GitHub 仓库（如 `assets/` 目录）
- Markdown 中使用相对路径引用
- 支持从相册选取、拍照、粘贴

### 2.3 文件管理

| 功能 | 说明 |
|------|------|
| Markdown 文件 | 使用 WYSIWYG 编辑器打开编辑 |
| 其他文本文件 | 以纯文本模式查看和编辑 |
| 非文本文件 | 仅浏览（图片预览，其他显示文件信息） |
| 文件操作 | 新建、删除、重命名文件和文件夹 |

### 2.4 AI Chat

| 功能 | 说明 |
|------|------|
| 独立 Chat 界面 | 与 AI 对话，支持 Markdown 渲染回复 |
| 多 LLM 支持 | 用户自行配置 API Key，支持 OpenAI / Anthropic / 其他兼容 API |
| 上下文感知 | Chat 时可携带当前编辑文件内容作为上下文 |
| 对话管理 | 新建/删除对话，对话历史本地持久化 |

**V2 扩展（非 MVP）**：
- 选中文字 → AI 改写/翻译/续写/总结（类 Cursor 内联编辑）
- AI 直接修改文档内容（用户确认后应用 diff）

### 2.5 离线支持

- 仓库克隆到本地后，无网络也可正常编辑
- 所有 Git 操作（commit）均在本地执行
- 联网后可手动 Push 同步到远端
- 离线期间的修改不会丢失

## 3. 用户流程

### 3.1 首次使用

```
打开 App → OAuth 登录 GitHub → 展示仓库列表 → 选择仓库 → Clone 到本地 → 进入文件浏览器
```

### 3.2 日常编辑

```
打开 App → 选择已克隆的仓库 → 浏览文件 → 点击 .md 文件 → WYSIWYG 编辑 → 保存到本地
```

### 3.3 提交推送

```
编辑完成 → 进入 Git 面板 → 查看变更文件列表 → 选择文件 → 填写 commit message → Commit → Push
```

### 3.4 AI Chat

```
编辑文件时 → 打开 Chat 面板 → 自动携带当前文件上下文 → 向 AI 提问 → 获取回答
```

### 3.5 冲突处理

```
Push 失败(远端有更新) → 提示用户 → 选择：Pull 合并 / 强制覆盖 / 取消 → 处理后重新 Push
```

## 4. 非功能需求

| 项目 | 要求 |
|------|------|
| 性能 | 打开 1000 行 Markdown 文件流畅无卡顿 |
| 存储 | 克隆的仓库存储在 App 沙盒内，支持用户手动清理 |
| 安全 | OAuth token 和 AI API Key 存储在 Keychain，不明文保存 |
| 兼容 | iOS 17+ |
