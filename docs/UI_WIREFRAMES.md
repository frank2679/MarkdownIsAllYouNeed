# MarkdownIsAllYouNeed — UI 线框图

> iPhone 竖屏设计，所有页面遵循 iOS Human Interface Guidelines

## 导航结构总览

```
App 启动
  │
  ├─ [未登录] → LoginView
  │
  └─ [已登录] → TabBar 主界面
                  ├── Tab 1: 仓库 (RepoListView)
                  │            └── FileTreeView
                  │                 ├── MarkdownEditorView
                  │                 ├── TextEditorView
                  │                 └── FilePreviewView
                  ├── Tab 2: AI Chat (ChatListView)
                  │            └── ChatView
                  └── Tab 3: 设置 (SettingsView)
```

  - **Git** 按钮 + 角标数字（未提交变更数）→ 打开 Git 面板

## 5. Markdown 编辑器页 (MarkdownEditorView)

**核心页面**。所见即所得编辑。

```
┌─────────────────────────────────┐
│  ←  hello.md        💬  ✓ 保存  │
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │ H1│H2│ B│ I│ ~│ •│☑│<>│""│─│ │
│ │ 📷│🔗│📊│∑ │                 │ │
│ └─────────────────────────────┘ │
├─────────────────────────────────┤
│                                 │
│  # Hello World                  │
│                                 │
│  这是一篇关于**设计方案**的文章。   │
│                                 │
│  ## 目标                        │
│                                 │
│  - [x] 完成需求分析              │
│  - [ ] 编写设计文档              │
│  - [ ] 开始开发                  │
│                                 │
│  > 引用：好的设计是简洁的          │
│                                 │
│  ```javascript                  │
│  const app = createApp()        │
│  app.start()                    │
│  ```                            │
│                                 │
│  | 功能  | 状态 |               │
│  |-------|------|               │
│  | 登录  | ✅   |               │
│  | 编辑  | 🚧   |               │
│                                 │
│                                 │
└─────────────────────────────────┘
```

**交互说明**：

**导航栏**：
- ← 返回（如有未保存修改，弹窗提示"保存/丢弃/取消"）
- 文件名（可点击重命名）
- 💬 按钮 → 打开 AI Chat（携带当前文件上下文）
- ✓ 保存按钮（保存到本地文件，非 Git commit）

**工具栏**（可横向滚动）：

```
第一排：H1  H2  B  I  ~  •  ☑  <>  ""  ─
第二排：📷  🔗  📊  ∑

说明：
H1/H2  = 标题
B      = 粗体
I      = 斜体
~      = 删除线
•      = 无序列表
☑      = 任务列表
<>     = 代码块
""     = 引用
─      = 分割线
📷     = 插入图片（弹出选择：相册/拍照）
🔗     = 插入链接
📊     = Mermaid 图表
∑      = LaTeX 公式
```

**编辑区域**：
- WKWebView 承载 Milkdown 编辑器
- 所见即所得：标题直接显示大号字，粗体直接加粗，代码块直接高亮
- 点击任意位置即可编辑
- 图片内联显示

**键盘弹出时**：
```
┌─────────────────────────────────┐
│  ←  hello.md        💬  ✓ 保存  │
├─────────────────────────────────┤
│                                 │
│  [编辑内容区域，自动缩小]          │
│                                 │
│  光标位置保持可见 |               │
│                                 │
├─────────────────────────────────┤
│ H1│H2│ B│ I│ ~│ •│☑│<>│📷│🔗│  │
├─────────────────────────────────┤
│         [iOS 键盘]              │
│                                 │
│                                 │
└─────────────────────────────────┘
```
- 工具栏跟随键盘顶部（作为 inputAccessoryView）
- 编辑区域自动调整大小，光标位置始终可见

## 6. Git 面板页 (GitPanelView)

从文件树页底部 "Git" 按钮进入。

```
┌─────────────────────────────────┐
│  ←  Git · my-blog               │
├─────────────────────────────────┤
│  main · ⚠ 3 个未提交变更          │
│                                 │
│  ┌────────────────────────┐     │
│  │ ↓ Pull    ↑ Push       │     │
│  └────────────────────────┘     │
├─────────────────────────────────┤
│                                 │
│  变更文件                        │
│                                 │
│  ☑ 📄 _posts/hello.md           │
│       修改 +12 -3               │
│                                 │
│  ☑ 📄 _posts/drafts/wip.md      │
│       新增 +45                  │
│                                 │
│  ☐ 📄 README.md                 │
│       修改 +1 -1                │
│                                 │
├─────────────────────────────────┤
│  Commit Message                 │
│ ┌─────────────────────────────┐ │
│ │ 更新博客文章，新增草稿         │ │
│ │                             │ │
│ └─────────────────────────────┘ │
│                                 │
│   ┌─────────────────────────┐   │
│   │     ✓  Commit & Push     │   │
│   └─────────────────────────┘   │
│   ┌─────────────────────────┐   │
│   │     ✓  仅 Commit         │   │
│   └─────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│   📁 仓库    💬 AI Chat    ⚙ 设置 │
└─────────────────────────────────┘
```

**交互说明**：
- **Pull/Push 按钮**：快捷操作，Pull 拉取远端，Push 推送本地
- **变更文件列表**：☑ 勾选 = 将纳入此次 commit，点击文件名 → 查看 diff
- **Commit Message**：手动输入，必填
- **Commit & Push**：一键提交并推送
- **仅 Commit**：只本地提交，不推送

**点击文件查看 Diff**：

```
┌─────────────────────────────────┐
│  ←  hello.md · Diff             │
├─────────────────────────────────┤
│                                 │
│  @@ -5,3 +5,12 @@              │
│                                 │
│    这是一篇文章。                │
│  - 旧的内容在这里                │
│  + 新的内容已经修改过了           │
│  + 增加了一些新的段落             │
│                                 │
│    ## 未修改的部分               │
│    这部分保持不变。              │
│                                 │
└─────────────────────────────────┘
```

**冲突弹窗**（Push 时检测到远端有更新）：

```
        ┌───────────────────────┐
        │  ⚠ 远端有新的变更       │
        │                       │
        │  远端有 2 个新 commit   │
        │  需要先合并才能推送      │
        │                       │
        │  [取消]                │
        │  [Pull 并合并]         │
        │  [强制推送]       ⚠    │
        └───────────────────────┘
```

## 11. 设计原则

1. **内容优先**：编辑器全屏，最小化 UI chrome
2. **手势友好**：返回用左滑，删除用左滑，一致的 iOS 手势
3. **状态可见**：同步状态、修改状态、离线状态始终可见
4. **渐进展示**：复杂操作（Git、AI）不强制，自然融入工作流
5. **容错设计**：危险操作（删除、强制推送）需二次确认
