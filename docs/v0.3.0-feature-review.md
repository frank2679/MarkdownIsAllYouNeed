## 二、新建文件 / 文件夹

### 2.1 在仓库根目录新建

**入口**：文件浏览器底部工具栏的 **`+`** 按钮（取代原来失效的 "New File" 按钮）。

**操作步骤**：
1. 进入任意仓库的文件浏览器。
2. 点击底部工具栏右侧 `+` 按钮，弹出菜单，选择 **New File** 或 **New Folder**。
3. 弹出 Sheet，顶部有 File / Folder 切换器（Segmented Picker）。
4. 在输入框填写名称：
   - 若选择 File 且不带扩展名（如输入 `hello`），底部会提示 "Will be created as 'hello.md'"，确认后自动加 `.md`。
   - 若选择 File 且带扩展名（如 `README.md`），按实际名称创建。
   - 若选择 Folder，创建目录，不自动加后缀。
5. 点击 **Create**，Sheet 关闭。

**预期结果**：
- 文件树立即刷新，出现新建的条目（位于仓库根目录）。
- 若新建的是 `.md` 或文本文件，自动跳转进入编辑器。
- Git 状态面板中该文件显示绿点（Added）。

### 2.2 在指定子目录新建

**入口**：长按文件树中的任意**文件夹**，弹出 Context Menu。

**操作步骤**：
1. 长按一个文件夹（如 `docs/`），弹出 Context Menu。
2. 选择 **New File**（在该目录下创建文件）或 **New Folder**（在该目录下创建子目录）。
3. 后续步骤与 2.1 相同。

**预期结果**：
- 新建条目出现在对应的子目录下，**不是**根目录。
- 例如：长按 `docs/` → New File → 输入 `guide` → 创建 `docs/guide.md`。

## 三、重命名文件 / 文件夹

**入口**：长按文件树中的任意**文件**或**文件夹**，弹出 Context Menu → 选择 **Rename**。

**操作步骤**：
1. 长按一个文件（如 `README.md`）或文件夹（如 `docs/`）。
2. 点击 **Rename**，弹出 Alert，标题显示 "Rename"，副标题显示当前文件名。
3. Alert 内有文本输入框，预填当前文件名。
4. 修改名称后点击 **Rename**，Alert 关闭。

**预期结果**：
- 文件树立即刷新，旧名称消失，新名称出现，位置不变（同一目录层级）。
- 文件/文件夹内容不变。
- 若文件正在编辑器中打开，编辑器内容不受影响（但编辑器标题栏文件名不会自动更新，属于已知限制）。

---

## 四、删除文件 / 文件夹

**入口**：长按文件树中的任意**文件**或**文件夹**，弹出 Context Menu → 选择 **Delete**。

**操作步骤**：
1. 长按一个文件或文件夹。
2. 点击 **Delete**（红色），弹出 Confirmation Dialog。
   - 删除文件：提示 "This will permanently delete this file."
   - 删除文件夹：提示 "This will permanently delete the folder and all its contents."
3. 点击 **Delete**（红色确认按钮），操作执行。
4. 点击 **Cancel** 取消操作。

**预期结果**：
- 删除后文件树立即刷新，对应条目消失。
- 删除文件夹会删除其所有子内容（本地文件系统层面，不可恢复）。
- Git 状态面板中被删除的已追踪文件显示红点（Deleted）。

---

## 五、拖拽移动文件 / 文件夹

**交互方式**：长按文件或文件夹（约 0.5 秒），拖起后移动到目标文件夹上方，松手即完成移动。

**操作步骤**：
1. 在文件树中长按想要移动的文件（如 `2026/note.md`）或文件夹（如 `2026/workflow/`）。
2. 拖动到目标文件夹（如 `docs/`），目标文件夹会显示淡蓝色高亮。
3. 松手，文件移动完成，文件树立即刷新。

**预期结果**：
- 文件/文件夹从原位置消失，出现在目标目录下。
- 文件内容不变。
- Git 状态面板中原路径显示 Deleted，新路径显示 Added（符合 Git 的 move 语义）。

**边界处理**：
- 拖入自身所在的目录（无效，不移动）。
- 将文件夹拖入其自身的子目录（无效，防止循环嵌套）。

## 六、边界情况 & 已知限制

| 情况 | 行为 |
|------|------|
| 创建时输入空名称 | "Create" 按钮置灰，无法确认 |
| 重命名时输入空名称 | 点 Rename 无效果（空名称被忽略） |
| 新建文件名与已有文件重名 | 安静地覆盖（iOS 文件系统默认行为），不弹出警告 |
| 删除 Recent 列表中的文件 | 文件从文件树和 Recent 列表中同时消失 |
| 删除文件夹（内含 Recent 文件） | 该文件夹下的所有文件从 Recent 列表中清除 |
| 拖拽到同一目录 | 静默忽略，不执行移动 |
| 重命名/删除后编辑器标题不更新 | 已知限制，v0.4.0 考虑修复 |
