# v0.5.0 Feature Review & Validation Guide

> 此文档用于上机验证 v0.5.0 的所有新增功能和 Bug 修复。

---

## 一、Bug Fix：Markdown 链接跳转

**预期**：在文档预览模式下点击链接，跳转到浏览器打开对应 URL。

**操作步骤**：
1. 打开任意含有 Markdown 链接的文件（如 `[Google](https://google.com)`）。
2. 文档处于**预览模式**（未进入编辑态）。
3. 点击链接文字。

**预期结果**：
- 系统浏览器打开对应 URL，文档不切换到编辑模式。

**边界**：
- 点击链接以外的位置 → 进入编辑模式（正常行为，见 Feature 1）。

## 二、Bug Fix：手机编辑不产生多余空行

**预期**：在手机上编辑已有文件，只新增一行时，保存后文件中只多一行，不产生多余空行，末尾保留单个换行符。

**操作步骤**：
1. 打开任意 Markdown 文件，记录当前行数和末尾内容。
2. 点击文档进入编辑模式，在某处新增一行内容。
3. 退出文档（自动保存）。
4. 重新打开文件确认内容。

**预期结果**：
- 只多出一行，段落之间无额外空行。
- 文件末尾有且只有一个 `\n`，原有末尾内容未被删除。

---

## 三、Bug Fix：拖拽文件到指定目录

**预期**：长按文件后可以拖拽到目标文件夹，目标文件夹有清晰的高亮反馈，松手后文件移动成功。

**操作步骤**：
1. 在文件树中长按一个文件（约 0.5 秒），进入拖拽状态。
2. 将文件拖到目标文件夹上方，观察高亮反馈。
3. 松手。

**预期结果**：
- 目标文件夹在拖拽悬停时有明显高亮（蓝色边框或背景色变化）。
- 文件从原路径消失，出现在目标文件夹下。
- Git 状态：原路径显示 Deleted，新路径显示 Added。

---

## 四、Feature：Notion 风格编辑模式

**预期**：进入文档时为只读预览模式，点击具体位置才进入编辑，退出文档自动保存，无 Save 按钮。

**操作步骤**：
1. 打开任意 Markdown 文件。
2. 观察初始状态：文档以预览模式显示，键盘不弹出，顶部无 Save 按钮。
3. 点击文档中的某个位置。
4. 观察编辑状态：键盘弹出，光标出现在点击位置，格式工具栏显示在键盘上方。
5. 编辑内容后，点击顶部 **Done** 按钮或直接导航回文件列表。

**预期结果**：
- 进入文档时是只读预览，不自动弹出键盘。
- 点击后切换为编辑模式，光标定位准确。
- 退出文档后内容已自动保存（重新打开文件内容与编辑一致）。
- 顶部不显示 Save 按钮。

## 五、Feature：Favorites 收藏

**预期**：长按文件或文件夹可以添加/移除收藏，收藏项显示在文件树的独立 Favorites section，重启 App 后持久保留。

**操作步骤**：
1. 在文件树中长按任意文件或文件夹，弹出 Context Menu。
2. 选择 **Favorite**（添加收藏）。
3. 观察文件树顶部出现 **Favorites** section，该文件/文件夹出现在其中。
4. 长按已收藏的条目，选择 **Unfavorite**（取消收藏）。
5. 退出 App 后重新打开，验证收藏持久化。

**预期结果**：
- 添加后立即在 Favorites section 显示。
- 取消后从 Favorites section 消失。
- 重启 App 收藏仍然存在（UserDefaults 持久化）。
- Favorites section 在 Recent 和 Files 之间显示。

## 六、Feature：Git Discard 修改回退

**预期**：在 Git 面板的变更文件列表中，可以对单个文件执行 Discard，将其恢复为远端原始内容；新增文件 Discard 后被删除。

**操作步骤**：

**场景 A：Discard 已修改的文件**
1. 编辑一个已追踪的文件并退出保存。
2. 打开 Git 面板，找到该文件（显示 Modified）。
3. 左滑文件行，点击 **Discard**，确认 Alert。

**预期结果**：
- 文件内容恢复为远端原始版本。
- Git 面板中该文件从变更列表消失。

**场景 B：Discard 新增文件**
1. 创建一个新文件（本地新增，未 push）。
2. 打开 Git 面板，找到该文件（显示 Added）。
3. 左滑文件行，点击 **Discard**，确认 Alert。

**预期结果**：
- 本地文件被删除。
- Git 面板中该文件从变更列表消失。
