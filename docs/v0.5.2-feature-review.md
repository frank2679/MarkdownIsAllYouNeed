# v0.5.2 Feature Review

> 目标：在 Markdown 阅读页右上角新增三点菜单，支持 Favorite、Move To 和字体大小调整；同时优化编辑模式交互（取消 Done 按钮，工具栏移到键盘上方）。

---

## 一、三点菜单入口

**位置**：`MarkdownEditorScreen` 顶部导航栏右上角，使用 `ellipsis.circle` 系统图标。

- 预览模式和编辑模式下均显示三点菜单（包含 Favorite / Move To / Font Size）
- **不再有 Done 按钮**（详见二）

---

## 二、编辑模式交互变更：取消 Done，收键盘即 Done

**变更前**：导航栏右上角有 Done 按钮，点击后保存并退出编辑模式。

**变更后**：
- 取消 Done 按钮。
- 收起键盘（下拉手势 / 点击非编辑区域）= Done：自动保存 + 切回预览模式。
- 监听 `UIResponder.keyboardWillHideNotification`：键盘消失时若处于编辑模式，触发 `switchMode(to: "preview")`（内含 auto-save 逻辑，无变化）。

---

## 三、编辑工具栏移到键盘上方

**变更前**：`EditorToolbar` 显示在页面顶部（VStack 最上方）。

**变更后**：
- `EditorToolbar` 作为键盘的 `inputAccessoryView`，随键盘弹起/收起动画，始终贴在键盘正上方。
- 键盘未弹起时（预览模式）：工具栏不可见。
- 键盘弹起时（编辑模式）：工具栏出现在键盘上方。

**实现方式**：在 `MarkdownEditorView` 中将 `WKWebView` 改为自定义子类 `KeyboardAccessoryWebView`，override `inputAccessoryView` 返回承载 `EditorToolbar` 的 `UIHostingController.view`：

```swift
class KeyboardAccessoryWebView: WKWebView {
    var accessoryView: UIView?
    override var inputAccessoryView: UIView? { accessoryView }
}
```

`EditorToolbar` 的 `onFormat` 回调通过 Coordinator 持有的闭包传递，与现有逻辑一致。

---

## 四、Feature：Favorite（收藏/取消收藏）

**前提**：`MarkdownEditorScreen` 接受 `repo: Repository?` 可选参数（从 `FileTreeView` 传入）。

**操作步骤**：
1. 在 Markdown 预览/编辑页，点击右上角 `···` 菜单。
2. 选择 **Favorite**（未收藏时）或 **Unfavorite**（已收藏时）。

**预期结果**：
- Favorite：文件被写入 `UserDefaults["favorites-{repo.fullName}"]`。
- Unfavorite：文件从同一 key 移除。
- 返回文件树后，Favorites section 即时更新（FileTreeView `.onAppear` 刷新）。

**边界**：
- 没有 repo 上下文（如从内链弹出的 sheet）：菜单中不显示 Favorite 和 Move To 项，仅显示 Font Size。

---

## 五、Feature：Move To（从编辑器移动文件）

**操作步骤**：
1. 点击右上角 `···` 菜单，选择 **Move To...**
2. 弹出 `MoveToSheet`（与文件树中的实现相同），选择目标目录。

**预期结果**：
- 移动前若文件有未保存修改，先执行 auto-save。
- 文件被移动到所选目录。
- 编辑器自动 dismiss（navigate back）。
- 返回文件树后，文件树刷新（`.onAppear` 触发）。

**边界**：
- 目标目录与当前目录相同时，不执行移动。

---

## 六、Feature：Font Size（字体大小，5 级）

**操作步骤**：
1. 点击右上角 `···` 菜单，展开 **Font Size** 子菜单。
2. 选择档位（当前选中项前显示 checkmark）。

**预期结果**：
- 选中后立即生效：WebView `body.style.fontSize` 更新。
- 设置持久化到 `UserDefaults["markdownFontSize"]`（全局，不区分 repo）。
- 重新打开编辑器时，应用上次选择的字体大小。
- 默认：Medium (16px)。

**字体档位（5 级）**：

| 档位    | px 值 |
|---------|-------|
| XS      | 12    |
| S       | 14    |
| M       | 16    |
| L       | 18    |
| XL      | 20    |

## 七、实现方案

### 7.1 涉及文件

| 文件 | 改动 |
|------|------|
| `MarkdownEditorScreen.swift` | 取消 Done 按钮；键盘消失监听；添加菜单、favorite 状态、move-to sheet、font size |
| `MarkdownEditorView.swift` | 用 `KeyboardAccessoryWebView` 子类承载 EditorToolbar；Coordinator 新增 `setFontSize`；`loadFileContent()` 应用初始字体 |
| `editor.js` | 新增 `setFontSize` bridge action |
| `FileTreeView.swift` | 传 `repo` + `onFileMoved` 给 MarkdownEditorScreen；`.onAppear` 刷新文件树和收藏 |

### 7.2 MarkdownEditorScreen 接口变更

```swift
struct MarkdownEditorScreen: View {
    let fileURL: URL
    let fileName: String
    var repo: Repository? = nil          // NEW（可选，不传则菜单隐藏 Favorite/Move To）
    var onFileMoved: (() -> Void)? = nil // NEW（文件被移动后回调 FileTreeView 刷新）
    ...
}
```

`relativePath` 由 `fileURL` 和 `repo.localPath` 计算得出。

### 7.3 键盘消失触发 Done

```swift
.onReceive(NotificationCenter.default.publisher(
    for: UIResponder.keyboardWillHideNotification)) { _ in
    if isEditMode { switchMode(to: "preview") }
}
```

`switchMode(to: "preview")` 已包含 isDirty 判断和 auto-save，无需额外改动。

### 7.4 EditorToolbar 作为 inputAccessoryView

`MarkdownEditorView` 中：
- `WKWebView` → `KeyboardAccessoryWebView`（override `inputAccessoryView`）
- 在 `makeUIView` 中创建 `UIHostingController(rootView: EditorToolbar {...})` 并绑定到 `accessoryView`
- `onFormat` 回调保存在 Coordinator，供 hosting controller 的 SwiftUI view 调用
- 移除 `MarkdownEditorScreen` VStack 顶部的 `EditorToolbar` 渲染逻辑

### 7.5 Font Size 桥接

**editor.js 新增 case：**
```js
case 'setFontSize':
    document.body.style.fontSize = payload.size + 'px';
    break;
```

**Coordinator 新增方法：**
```swift
func setFontSize(_ size: Int) {
    let js = "window.bridge.receive({ action: 'setFontSize', version: 1, payload: { size: \(size) } });"
    webView?.evaluateJavaScript(js, completionHandler: nil)
}
```

字体大小在 `loadFileContent()` 末尾链式调用初始化；
`MarkdownEditorScreen` 使用 `@AppStorage("markdownFontSize")` + `.onChange(of: fontSize)` 响应用户切换。

### 7.6 FileTreeView 调用变更

```swift
MarkdownEditorScreen(
    fileURL: ...,
    fileName: ...,
    repo: repo,
    onFileMoved: { refreshTree(); loadFavorites() }
)
```

FileTreeView 添加 `.onAppear { refreshTree(); loadFavorites() }` 以在从编辑器返回时刷新。
