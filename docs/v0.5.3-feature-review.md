# v0.5.3 Feature Review

> 目标：修复长时间切换 app 后文档内容丢失的 bug；工具栏增加 Undo 按钮；修复 H1/H2 等格式按钮无法取消；新增分享链接功能。

---

## 一、Bug Fix：长时间后台后文档内容为空

**根因**：iOS 在 app 后台久置后会终止 WKWebView 的 Web Process 以回收内存，恢复前台时 WebView 内容被清空，但 `loadFileContent()` 不会再次触发（已有 `contentLoaded = true` 守卫）。

**修复方案**：在 `MarkdownEditorScreen` 中监听 `UIApplication.willEnterForegroundNotification`，前台恢复时调用 Coordinator 的新方法 `reloadContentIfEmpty(fallbackMarkdown:)`：

1. JS 检测 `editor.innerHTML` 是否为空（或仅为 `<br>`）
2. 若为空：优先用内存中的 `currentMarkdown`（含未保存修改）重新渲染；若内存也为空则从磁盘读取
3. 恢复后仍保持当前 mode（preview/edit）

**涉及文件**：`MarkdownEditorScreen.swift`、`MarkdownEditorView.swift`

---

## 二、Feature：工具栏增加 Undo / Redo 按钮

**操作**：
- 点击 `↩`（`arrow.uturn.backward`）按钮，回退上一步编辑操作
- 点击 `↪`（`arrow.uturn.forward`）按钮，重做上一步回退

**实现**：
- `editor.js` 新增 `'undo'` / `'redo'` bridge action：`document.execCommand('undo'/'redo', false, null)`
- `Coordinator` 新增 `undo()` / `redo()` 方法
- `EditorToolbar` 最左侧新增 undo + redo 按钮，与格式按钮用 Divider 分隔

**预期结果**：
- ↩ 回退一步，连续点击多步回退
- ↪ 重做，连续点击多步重做

**边界**：无可回退/重做历史时无效果（浏览器行为）

## 三、Bug Fix：格式按钮无法取消（bold / italic / strikethrough / H1 / H2）

**根因**：markdown 渲染输出 `<strong>`/`<em>`/`<del>` 标签，但 iOS WebKit 的 `execCommand('bold/italic/strikethrough')` 内部 toggle 检测针对 `<b>`/`<i>`/`<strike>` 或 inline style，导致光标在已格式化文字内时无法识别并取消格式——与已修复的 blockquote/code 问题完全同类。

**修复方案**：与 `toggleBlockquote()` / `toggleInlineCode()` 相同的 DOM-based toggle 模式：

| 按钮 | 检测标签 | 取消方式 | 应用方式 |
|------|----------|----------|----------|
| Bold | `<strong>`, `<b>` | unwrap DOM 节点 | `execCommand('bold')` |
| Italic | `<em>`, `<i>` | unwrap DOM 节点 | `execCommand('italic')` |
| Strikethrough | `<del>`, `<s>`, `<strike>` | unwrap DOM 节点 | `execCommand('strikethrough')` |
| H1 | `<h1>` | `formatBlock('p')` | `formatBlock('h1')` |
| H2 | `<h2>` | `formatBlock('p')` | `formatBlock('h2')` |

**注**：unorderedList / orderedList 使用 `insertUnorderedList`/`insertOrderedList`，iOS WebKit 对这两个命令的 toggle 是可靠的，无需修改。

**涉及文件**：`editor.js`

## 四、Feature：分享（两种方式）

**入口**：编辑器 `···` 菜单新增两个分享选项（仅当 repo 上下文可用时显示）。

---

### 4a. Share Link（公开仓库 / GitHub blob URL）

**操作**：选择 **Share Link**，系统分享面板弹出 GitHub blob URL。

**链接格式**：
```
https://github.com/{repo.fullName}/blob/{repo.defaultBranch}/{relativePath}
```

**实现**：`ShareLink(item: url)`，零额外状态管理。

**适用场景**：公开仓库，接收方有 GitHub 账号的私有仓库。

---

### 4b. Share as Gist（私有仓库 / 生成 public gist 链接）

**操作**：选择 **Share as Gist**，调用 GitHub API 创建 public gist，完成后系统分享面板弹出 gist URL。

**流程**：
1. 调用 `POST https://api.github.com/gists`（用已有 auth token）
2. 创建 public gist，文件名为当前 `fileName`，内容为当前 markdown
3. 返回 gist URL：`https://gist.github.com/{gist_id}`
4. 弹出系统分享面板

**实现**：
- `GitHubProvider` 新增 `createGist(fileName:content:) async throws -> URL` 方法
- `MarkdownEditorScreen` 新增 `@State private var isCreatingGist = false`（显示 loading）
- 创建成功后用 `@State private var gistURL: URL?` 触发 `ShareLink`

**错误处理**：创建失败时显示 Alert 提示。

---

### 4c. Export HTML（离线，无需网络）

**操作**：选择 **Export HTML**，本地将 markdown 渲染为完整 HTML 文件，弹出系统分享面板（AirDrop、存储到文件 app、发送给联系人等）。

**流程**：
1. 取当前 `currentMarkdown`（或从磁盘读取）
2. 在 Swift 端调用 WKWebView 获取当前 `document.documentElement.outerHTML`，或直接拼接 HTML 字符串（复用 `editor.css` 样式内联）
3. 写入临时文件 `{fileName}.html`
4. `ShareLink(item: htmlFileURL)` 弹出系统分享面板

**实现**：纯本地操作，无网络请求，无需 auth token。

---

**菜单结构**（repo 上下文可用时）：
```
Favorite / Unfavorite
Move To...
─────────────
Share Link
Share as Gist
Export HTML
─────────────
Font Size ▶
```

### 5.2 Bug Fix：前台恢复内容重载

```swift
// MarkdownEditorScreen
.onReceive(NotificationCenter.default.publisher(
    for: UIApplication.willEnterForegroundNotification
)) { _ in
    coordinatorRef?.reloadContentIfEmpty(
        fallbackMarkdown: currentMarkdown,
        fontSize: fontSizeRaw
    )
}

// Coordinator 新增方法
func reloadContentIfEmpty(fallbackMarkdown: String, fontSize: Int) {
    webView?.evaluateJavaScript("document.getElementById('editor')?.innerHTML ?? ''") { [weak self] result, _ in
        let html = (result as? String) ?? ""
        let isEmpty = html.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty
            || html == "<br>" || html == "<br/>"
        guard isEmpty else { return }
        DispatchQueue.main.async { [weak self] in
            guard let self else { return }
            let markdown = fallbackMarkdown.isEmpty
                ? (FileManagerService.shared.readFileContent(at: self.parent.fileURL) ?? "")
                : fallbackMarkdown
            let jsonString = (try? JSONEncoder().encode(markdown))
                .flatMap { String(data: $0, encoding: .utf8) } ?? "\"\""
            let js = """
                window.bridge.receive({ action: 'setContent', version: 1, payload: { markdown: \(jsonString) } });
                window.bridge.receive({ action: 'setMode', version: 1, payload: { mode: 'preview' } });
                window.bridge.receive({ action: 'setFontSize', version: 1, payload: { size: \(fontSize) } });
                """
            self.webView?.evaluateJavaScript(js, completionHandler: nil)
        }
    }
}
```

### 5.4 DOM-based toggle（bold / italic / strikethrough / heading）

```js
// 复用已有 closestElement(node, tag) 工具函数

function toggleBold() {
    const anchor = window.getSelection()?.anchorNode;
    const el = closestElement(anchor, 'strong') || closestElement(anchor, 'b');
    el ? unwrapElement(el) : document.execCommand('bold', false, null);
}

function toggleItalic() {
    const anchor = window.getSelection()?.anchorNode;
    const el = closestElement(anchor, 'em') || closestElement(anchor, 'i');
    el ? unwrapElement(el) : document.execCommand('italic', false, null);
}

function toggleStrikethrough() {
    const anchor = window.getSelection()?.anchorNode;
    const el = closestElement(anchor, 'del') || closestElement(anchor, 's')
             || closestElement(anchor, 'strike');
    el ? unwrapElement(el) : document.execCommand('strikethrough', false, null);
}

function toggleHeading(tag) {
    const anchor = window.getSelection()?.anchorNode;
    const el = anchor && anchor.nodeType === 3 ? anchor.parentElement : anchor;
    document.execCommand('formatBlock', false,
        (el && el.closest(tag)) ? 'p' : tag);
}

// 共用 unwrap 辅助
function unwrapElement(el) {
    const parent = el.parentNode;
    while (el.firstChild) parent.insertBefore(el.firstChild, el);
    parent.removeChild(el);
}
```
