# v0.5.5 Feature Review — App 介绍网站

## 产品定位（更新后）

**MarkdownIsAllYouNeed** 是一款 AI native 的 Markdown 应用，以 Markdown 作为人与 AI 协作的语言：

- **跨平台同步**：基于 Git，当前通过 GitHub 实现——你的内容是标准文件，不被任何平台锁定
- **AI 协作**：用 Markdown 记录想法，AI 可以直接读写你的文件，像 Claude Code 一样与你的知识库协作（非 chatbot，是真正的文件级 AI 交互）

核心哲学：**大道至简**——用最朴素的格式（Markdown）+ 最开放的协议（Git），构建 AI 时代的个人知识基础设施。

## 功能范围

### 1. 网站目标

对外展示 App 的产品理念和核心功能，吸引目标用户（开发者 / 技术写作者 / AI 重度用户）。

### 2. 技术方案

- **技术栈**：纯静态 HTML + CSS（无框架，轻量，可 GitHub Pages 直接托管）
- **文件位置**：项目根目录 `website/` 目录，PR 时一起提交

```
website/
├── index.html
├── style.css
└── assets/
    └── screenshots/     # App 截图（后续补充）
```

### 3. 页面结构

**Hero**
- 产品名 + 一句话定位（体现 AI native + Markdown + Git）
- CTA：App Store 下载（暂占位）

**Philosophy（产品哲学）**
- 核心理念：Markdown 是 AI 时代最好的人机协作语言
- 大道至简：不锁定平台，内容永远是你的

**Features（核心功能）**
1. AI 文件协作 — AI 直接读写你的 Markdown 文件
2. Git 同步 — 基于 GitHub，跨设备、跨平台随时访问
3. WYSIWYG 编辑 — Notion 风格所见即所得，不失 Markdown 本质
4. 离线优先 — 本地 Git，无网络也能编辑提交
5. 文件管理 — 完整的仓库文件树，新建/删除/移动
6. Git 操作 — diff、commit、push、discard，完整工作流

**Footer**
- GitHub 链接
- 版权信息

### 4. 视觉风格

- 简约、克制、有品味，体现"大道至简"哲学
- 以文字和排版为核心，减少装饰元素
- 色调：深色或白色背景均可（待参考网站确认后定）
- 字体：等宽/无衬线，呼应 Markdown/代码的技术气质
