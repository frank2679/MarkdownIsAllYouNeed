## Round 1

当前版本是 v0.2.0，已经上机验证过以下基本功能

1. 可以登录 git 账号，完成最基本的 git 操作，包括 clone, push, diff
2. 可以查看 markdown 文件，png
3. 可以对 markdown 文件做基本的编辑操作，比如添加列表

当前的问题

1. 占用空间特别大，目前仅 clone 了两个仓库，总大小应该是 104MB，实际目前占用了 226MB，中间我操作过删除仓库，又重新 clone，发现它会重新拉取数据，而不是直接使用之前拉好的。这个点可以优化。
2. 无法创建新文件，有一个创建的按钮，但是没有生效。
3. 缺少测试，后续的开发先为每个特性添加必要的测试，然后开发来让测试通过。

当下要做的事情

1. 基于上面列出的问题，更新版本规划，ai feature 往后排，优先解决上面的问题，这些问题不解决，这个 app 还是等于无法使用，首要目标是让我能够使用这个 app 有一个相对不错的体验来操作我的 markdown 文件，然后上传到 git 远端进行同步。
2. 在文件操作方面参考 notion app ，它的体验很棒。
3. 开始开发前让我 review feature，然后先开发测试，再进行开发，最后通过测试。完成后更新文档，让我 review。我好上机验证功能。
