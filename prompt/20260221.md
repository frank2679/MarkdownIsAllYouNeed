## 本轮目标：编辑体验优化（v0.5.0）

### Bug Fix（优先）

#### Bug 1：Markdown 链接无法跳转
- **根因**：WKWebView 的 `contentEditable` 模式下，点击 `<a>` 标签不触发导航，而是被编辑模式拦截
- **修复**：
  - `editor.js`：添加 `click` 事件监听器，检测 `<a>` 标签点击，通过 bridge 发送 `linkClicked` 消息
  - `MarkdownEditorView.swift`：在 Coordinator 中处理 `linkClicked` 消息，用 `UIApplication.shared.open()` 打开外部链接

#### Bug 2：手机编辑多出空行
- **根因**：iOS 在 `contentEditable` 中按回车会插入 `<div><br></div>` 结构，`htmlToMarkdown` 对每个 div 添加 `\n`，导致多余空行。同时 `.trim()` 删除了文件末尾的换行符
- **修复**：
  - `editor.js`：在 `htmlToMarkdown` 输出后规范化：将 3+ 个连续 `\n` 压缩为最多 2 个
  - `editor.js`：`nodeToMarkdown` 中处理 `<div><br></div>` 模式（仅包含 `<br>` 的 div 视为单个换行）
  - `editor.js`：`getMarkdown()` 在最终结果末尾保留单个 `\n`（与文件约定一致）

#### Bug 3：拖拽无法到指定路径
- **根因**：`DisclosureGroup` label 的垂直 padding 仅 2pt，drop target 区域太小；且 `DisclosureGroup` 在 `List` 中对 drop 事件的处理有限制
- **修复**：
  - `FileNodeRow.swift`：增大 folder row 的垂直 padding，更明显的 isDropTargeted 视觉反馈
  - `FileNodeRow.swift`：确保 `.contentShape(Rectangle())` 在 `.dropDestination` 之前正确应用

### 新功能

#### Feature 1：Notion 风格编辑模式
- 进入文档时：**预览模式**（非编辑态，HTML 只读渲染）
- 点击具体位置：切换到**编辑模式**（keyboard 弹出，contentEditable 激活）
- 退出文档时：自动保存（无需 Save 按钮）
- 移除顶部 Save 按钮
- 实现方案：
  - `editor.js`：添加 `setMode(mode)` 桥接命令（`preview` / `edit`），切换 `contentEditable` 状态；在 preview 模式下点击触发 `modeChangeRequested` 消息
  - `MarkdownEditorView.swift`：暴露 `setMode(mode:)` 方法给 Coordinator，添加 `onModeChangeRequested` 回调
  - `MarkdownEditorScreen.swift`：管理 `isEditMode` 状态；`onDisappear` 时自动保存；移除 Save button

#### Feature 2：Favorites 收藏功能
- 支持对文件/路径添加到 Favorites
- 显示在 FileTreeView 的独立 Section（在 Recent 和 Files 之间）
- 通过 context menu（长按）添加/移除
- 持久化到 `UserDefaults`（key: `favorites-{repo.fullName}`）
- 修改文件：`FileTreeView.swift`（添加 favorites section + 管理逻辑）、`FileNodeRow.swift`（添加 Favorite/Unfavorite context menu 项）

#### Feature 3：Git Discard 功能
- 在 GitPanelView 的 Changed Files 列表中，每个文件行支持 swipe-to-discard（或 context menu）
- Discard 操作：从 `.originals/` 缓存或 GitHub API 拉取原始内容，还原本地文件
- 新增 `GitService.discardChanges(path:repo:token:) async throws`
  - 如果 `.originals/` 有缓存 → 直接用缓存还原
  - 如果是新增文件（added）→ 删除本地文件
  - 如果没有缓存 → 从 GitHub API 拉取原始内容
- `GitPanelView.swift`：添加 discard 确认 alert + 调用 GitService
