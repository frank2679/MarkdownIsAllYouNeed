Philosophy

The Simplest Tools
Are the Most Powerful

Markdown is plain text. Git is open protocol. Together, they form the most durable foundation for your ideas — readable by humans and AI alike, now and forever.

📄

Plain Text, Forever

Your notes are standard Markdown files. Open them in any editor, on any device, 10 years from now. No proprietary format, no lock-in.

⑂

Git as the Protocol

Sync through GitHub. Every change is versioned, every file has history. The same protocol that powers the world's software powers your knowledge.

✦

AI as Your Collaborator

Markdown is the native language of AI. Your files are directly readable and writable by AI — not through a chat interface, but as a true file-level collaborator.

Everything You Need,
Nothing You Don't

✍️

WYSIWYG Editing

Notion-style editor that renders as you type. Headings, bold, lists, code blocks, tables — formatted beautifully, stored as plain Markdown.

⑂

GitHub Sync

Clone any repo, edit on your phone, push back. Your changes land directly in GitHub — no intermediary, no sync magic.

📂

File Management

Browse the full repository tree. Create, rename, move, and delete files and folders — complete file management from iOS.

🔄

Offline First

Everything works without internet. Edit and commit locally, sync when you're back online. Your work never waits for a connection.

📋

Git Operations

View diffs, commit, push, pull, and discard changes. A real Git client — not a simplified abstraction.

🔗

Share & Export

Share as a GitHub link, create a public Gist, or export as PDF and HTML. Multiple ways to get your writing out into the world.
